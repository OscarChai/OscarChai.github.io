Principle 1

Shop the way you already know how

Every control below is one a customer has already used on some other shop: a search bar at the top, a cart icon that fills up, an Add to Cart button, and a checkout button that starts payment. Nothing here needs to be explained first.

Try it: search, add a couple of products to the cart, then open the account icon to see the familiar login form.
